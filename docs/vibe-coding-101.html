바이브 코딩이란?

코드를 쓰지 않고 한국어 지시만으로 만듭니다

코드는 AI가 작성합니다. 사람은 무엇을 만들지 정하고 결과를 확인합니다

바이브 코딩은 코드를 직접 입력하는 대신 필요한 일을 말로 설명하고, AI가 그에 맞는 코드를 작성해 실행하도록 하는 작업 방식입니다. 사람이 맡는 몫은 무엇을 만들지 정하고 결과를 확인하는 일입니다.

이 방식을 실제로 구현하는 대표 도구는 Claude Code(Anthropic)와 Codex(OpenAI)입니다. 두 도구 모두 데스크톱 앱에서 지시를 받으면 컴퓨터의 폴더를 읽고, 파일을 만들거나 고치고, 실행 결과까지 보여 줍니다. 하는 일은 사실상 같습니다. 차이는 출시 시점과 세부 기능뿐이므로 어느 쪽으로 시작해도 무방합니다.

용어는 2025년 2월에 등장했습니다

2025년 2월 2일, 안드레이 카파시가 X에 짧은 글 하나를 올렸습니다. 그는 AI가 내놓는 코드를 그대로 받아들이고 코드 자체는 확인하지 않는 방식을 vibe coding이라고 불렀습니다. OpenAI 창립 멤버이자 테슬라 AI 총괄을 지낸 인물의 문장 하나가 그대로 업계 용어로 자리 잡았습니다.

설치 프로그램

시작에 필요한 프로그램

1
데스크톱 앱 필수
선택한 도구의 앱을 설치합니다. 맥과 윈도우 모두 같은 설치 파일 하나를 사용합니다. Claude Code는 Claude Desktop, Codex는 ChatGPT 앱입니다. 두 앱을 함께 설치해도 서로 간섭하지 않습니다.
Claude 데스크톱 앱 설치 ChatGPT 데스크톱 앱 설치
2
Git 필수
Git은 파일이 바뀐 과정을 시점마다 저장해두는 도구입니다. 작업이 잘못돼도 이전 상태로 한 번에 되돌릴 수 있는 안전망입니다. 설치만 해 두면 Claude Code와 Codex가 필요할 때 알아서 호출합니다. 설치 방법은 운영체제마다 다릅니다. 아래에서 해당 항목을 펼쳐 확인하세요.
만든이 2005년 리누스 토르발스(리눅스를 만든 사람) · 소유 특정 회사가 아닌 오픈소스로, 커뮤니티가 관리합니다(현 관리자 유니오 하마노). 저장·공유 서비스인 GitHub(마이크로소프트 소유)과는 다른 프로그램입니다. · 이름 뜻 'git'은 영국 속어로 '멍청하고 고집스러운 사람'을 가리키는 말입니다. 만든 리누스 토르발스가 "내 프로젝트엔 늘 내 이름을 붙인다"며 자신을 빗대 농담처럼 붙인 이름입니다.
Windows Windows에서 Git 설치하는 법(설치 완료 후 반드시 리부팅)
▾
윈도우 사양 먼저 확인

설치 파일은 32-bit / 64-bit / ARM64로 나뉩니다. Windows 키 + Pause(또는 시작 → 설정 → 시스템 → 정보)를 열고 "시스템 종류" 항목을 확인하세요. "x64 기반"이면 64-bit(대부분 여기), "x86 기반"이면 32-bit, "ARM 기반"이면 ARM64입니다.

  1. git-scm.com/download/win에서 사양에 맞는 파일을 내려받습니다. 64-bit는 메인 버튼, 그 외는 페이지 아래 "Other Git for Windows downloads"에서 고릅니다.
  2. 내려받은 파일을 실행한 뒤 옵션 화면은 모두 Next로 넘기고 마지막에 Install을 누릅니다. 기본값 그대로가 가장 안전합니다. "Finish"가 표시되면 창을 닫습니다.
  3. 설치가 끝나면 PC를 한 번 재부팅합니다. 재부팅해야 윈도우가 Git을 인식하고, AI가 곧바로 호출할 수 있습니다.

맥에는 Git이 시스템에 포함돼 있어 별도로 내려받을 필요가 없습니다. Cmd + Space로 Spotlight를 열어 터미널을 실행하고, 아래 한 줄을 붙여 넣은 뒤 엔터를 누릅니다. 설치 창이 나타나면 "설치"를 누르면 끝납니다.

Terminal (macOS)
xcode-select --install

설치가 이미 끝났다는 뜻입니다. 터미널을 닫고 다음 단계로 넘어가세요.

3
Python 선택
Python은 데이터 처리·분석·자동화에 많이 쓰는 프로그래밍 언어입니다. AI는 복잡한 계산이나 데이터 작업을 할 때 이 언어로 코드를 작성해 실행합니다. 시작 단계에서는 필요하지 않습니다. 맥은 앞 단계에서 xcode-select --install을 실행하면 Python 3가 함께 설치됩니다. 다만 이때 들어오는 버전은 낮은 편이라, 본격적인 데이터 분석에는 최신 버전을 따로 설치하는 편이 낫습니다. 윈도우는 간단한 표 작업까지 Python 없이 처리되지만, 데이터 분석을 맡길 계획이라면 아래 방법으로 미리 설치해 두세요.
만든이 1991년 귀도 반 로섬 · 소유 특정 회사가 아닌 오픈소스로, 비영리 단체인 파이썬 소프트웨어 재단(PSF)이 관리합니다.
Windows Windows에 Python 설치하는 법
▾

가장 간단한 방법은 터미널 한 줄입니다. 시작 메뉴에서 PowerShell이나 명령 프롬프트(cmd)를 열고 아래 명령을 붙여 넣으세요. 둘 중 어느 쪽이든 무방합니다. 윈도우 10과 11에 기본 내장된 winget이 설치를 진행하고 PATH도 자동으로 등록합니다.

PowerShell 또는 CMD
winget install -e --id Python.Python.3.13

설치가 끝나면 터미널을 닫았다 다시 열거나 PC를 재부팅합니다. 그래야 Python이 인식됩니다. python --version을 입력해 버전 번호가 출력되면 완료입니다.

winget이 없다고 나오면

python.org/downloads/windows에서 설치 파일을 내려받아 실행하고, 첫 화면의 "Add python.exe to PATH"에 반드시 체크한 뒤 "Install Now"를 누릅니다.

Mac Mac에 최신 Python 설치하는 법
▾

먼저 지금 깔린 버전을 확인합니다. 터미널을 열고 아래를 입력하세요. 3.11 이상이면 그대로 쓰셔도 됩니다.

Terminal (macOS)
python3 --version

3.9처럼 낮은 버전이 나오면 최신 버전을 따로 설치합니다. 맥에는 윈도우의 winget 같은 설치 도구가 없어 Homebrew를 먼저 깝니다. 맥에서 개발 도구를 설치할 때 표준으로 쓰는 관리자입니다. 중간에 맥 로그인 비밀번호를 물어보면 입력하고 엔터를 누릅니다.

① Homebrew 설치 (이미 있으면 건너뜁니다)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
② 최신 Python 설치
brew install python

설치가 끝나면 터미널을 닫았다 다시 열고 python3 --version을 다시 입력합니다. 올라간 버전 번호가 출력되면 완료입니다.

기존 Python은 그대로 둡니다

시스템에 들어 있던 /usr/bin/python3은 macOS가 쓰는 것이므로 지우지 마세요. Homebrew로 설치한 최신 버전이 앞서 잡히도록 자동으로 설정됩니다.

잘 쓰는 법

잘 쓰는 6가지 습관

Claude Code와 Codex에 모두 적용됩니다

1
만들 것부터 정리하고 시작하기
곧바로 "만들어줘"라고 지시하면 방향이 어긋난 채로 작업이 진행됩니다. 지시하기 전에 무엇을 만들지 짧게 정리하세요. 기획자·개발자·실사용자 세 관점으로 검토하게 하면 빠진 부분이 드러납니다.
2
작게 나누어 지시하기
"1단계만 먼저 만들어줘, 확인하고 이어서 진행할게"라고 지시하는 편이 한 번에 전부 맡기는 것보다 안전합니다.
3
시작 전과 중간 결과 시점에 백업하기
두 도구 모두 파일을 직접 수정하고 삭제합니다. 작업 전에 "git commit으로 현재 상태부터 저장해줘"라고 지시하고, 중간 결과가 만족스러우면 한 번 더 저장하세요. Git을 몰라도 AI가 대신 처리합니다.
4
구체적으로 요청하기
"예쁘게 만들어줘"보다 "배경은 흰색, 텍스트는 16px 이상, 버튼은 파란색"처럼 색과 크기, 동작을 지정하는 편이 정확합니다.
5
중간에 멈추고 개입하기
예상과 다른 방향으로 진행되면 즉시 "잠깐, 이 부분은 다시 생각해보자"라고 중단시키세요. 빨리 멈출수록 되돌릴 분량이 줄어듭니다.
6
반복하는 규칙은 파일로 남기기
매번 같은 주의사항을 다시 적고 있다면 그것은 규칙입니다. 작업 폴더의 AGENTS.md에 적어 두면 다음 대화부터 자동으로 읽습니다. Claude Code는 CLAUDE.md도 같은 용도로 읽으므로, 내용은 AGENTS.md에 두고 CLAUDE.md에는 그 파일을 참조하라는 한 줄만 적으면 두 도구가 같은 규칙으로 작동합니다.
규칙 파일 만들기 부탁 예시
이 폴더에 AGENTS.md를 만들어줘. 파일을 고치기 전에 항상 git commit부터 하고, 결과는 한국어로 설명하고, 내가 확인하기 전에는 파일을 지우지 않는다는 규칙을 넣어줘.

"확인되지 않은 개발자"라며 실행이 안 됩니다 macOS

맥의 보안 안내입니다. 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 "그래도 열기" 버튼을 누르세요.

"Claude Code" 메뉴가 안 보입니다 공통

앱이 구버전일 수 있습니다. 종료한 뒤 다시 열면 최신 버전으로 갱신됩니다.

ChatGPT 앱에서 Codex가 보이지 않습니다 공통

Codex는 위쪽 탭이 아니라 좌측 상단 서비스 이름에 있습니다. "ChatGPT"를 눌러 목록에서 Codex를 선택하세요. 전환하면 Work 탭이 사라지는 것이 정상입니다.

폴더 접근을 허용했는데 읽지 못한다고 합니다 공통

맥은 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더목록에서 해당 앱이 체크돼 있는지 확인하세요. 윈도우는 OneDrive 동기화 폴더를 피하고 일반 로컬 폴더를 지정하세요.

회사 PC라서 설치가 막힙니다 공통

사내 IT 담당자에게 데스크톱 앱과 Git 설치를 요청하세요. 두 프로그램 모두 공식적으로 검증된 소프트웨어입니다.
