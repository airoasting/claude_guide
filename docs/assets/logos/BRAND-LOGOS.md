# 기업 로고 출처

token-saving.html 배경 섹션(사례 카드)에서 쓰는 식별용 로고입니다.

| 파일 | 원본 | 라이선스 |
|---|---|---|
| `brand-uber.svg` | [Uber logo 2018.svg](https://commons.wikimedia.org/wiki/File:Uber_logo_2018.svg) | Public domain (Wikimedia Commons) |
| `brand-microsoft.svg` | [Microsoft logo (2012).svg](https://commons.wikimedia.org/wiki/File:Microsoft_logo_(2012).svg) | Public domain (Wikimedia Commons) |
| `brand-snu.png` | 서울대학교 공식 [대학상징 · 정장](https://www.snu.ac.kr/about/symbol/ui) 페이지의 `about-symbol-bi_lg.png` | 서울대학교 보유 |

우버와 마이크로소프트는 내려받은 뒤 `width`, `height` 고정값만 제거하고 `viewBox`를 남겨 CSS로 크기를 잡게 했습니다.

서울대는 공식 정장(VERITAS LUX MEA 원형 엠블럼)입니다. 원본 이미지가 왼쪽 도형과 오른쪽 그리드 가이드를 나란히 담고 있어
왼쪽 절반만 잘라내고 투명 여백을 제거한 뒤 높이 180px로 다시 만들었습니다. 도형과 색(#003380)은 원본 그대로이며 변형하지 않았습니다.

퍼블릭 도메인은 저작권 기준입니다. 상표권은 각 사에 있으므로 해당 조직을 가리키는 식별 용도로만 씁니다.
로고를 변형하거나 후원, 제휴를 암시하는 자리에는 쓰지 않습니다.
