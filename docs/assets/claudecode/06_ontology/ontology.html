9개. 함정 두 개는 R1과 R2로 정리

R1매장 동일성

매출데이터는 매장명, 사건로그는 구코드·신코드·약칭을 씀. 신코드는 그대로, 구코드(P-)는 구매장코드로, 이름은 매장명·별칭으로 해석함. "본사"·"전 매장"은 9곳 범위. 사건 39건 전부 해석됨.

R2배달수수료는 요금항목

고객이 내는 배달비(FEE-01)라 상품이 아님. 매출합(객단가·이익률 분모)에는 넣고, 메뉴·공급사 분석에서는 뺌. 매장이 배달앱에 내는 플랫폼수수료(비용)와 다른 개념. 배달비 인하(EV-010) 후 비중 11.6% → 7.7%로 데이터와 일치.

R3매장·월 값은 한 번만

카테고리 단위 지표는 매출액 하나. 나머지 33개는 6행 반복이라 월간실적에 한 번만 둠.

R4실적과 추정 분리

2026-09~10 추정 18건은 질문 답과 사건 검증에 쓰지 않음.

R5확인 등급 = 신뢰도

확인 35, 추정 3(EV-005·023·027), 미확인 1(EV-026). 추정·미확인은 데이터로 검증한 뒤 씀.

R6관계의 유효 기간

코드 체계 2022-09 전환, 메뉴 출시~단종·여름 한정, 배달비 2021-07, 배민 수수료 2024-11, 밀크팜 단가 2026-01, 충장로 점주 2026-01.

R7경유 관계

세트의 공급사는 구성 메뉴를 거쳐 정함. 포장재(SUP-06)는 배달·포장 비중에 비례하는 공통 원가.

R8정합성 제약

객단가, 이익률, 주문 비중 합, 시간대 비중 합, 배달앱 주문수 상한. 5개 모두 738건 통과. 손익 잔차(467건)·로열티율(24건)은 참고.

R9정정 후 값만 사실

변경이력 1,539건(이익률 674, 객단가 541, 배달앱 주문수 165, 주문 비중 87, 시간대 비중 69, 행·날짜 3)은 정정기록으로 남기고 정정 후 값을 씀. 사건로그 문장 속 수치가 데이터와 다르면 데이터를 씀.
