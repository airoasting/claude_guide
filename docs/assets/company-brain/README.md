# LLM Wiki 실습용 샘플 문서

가상의 회사 한 곳이 넉 달 동안 남긴 문서 8개입니다.
`karpathy-llm-wiki` 스킬(https://github.com/Astro-Han/karpathy-llm-wiki)로 실습할 때 씁니다.

## 폴더 구성

```
company-brain-sample/
├── raw/company/          ← 그대로 작업 폴더에 옮겨 넣는 원본 7개
└── sensitive-excluded/   ← 일부러 raw/ 밖에 둔 대외비 1개 (옮기지 않습니다)
```

`raw/` 폴더를 통째로 작업 폴더에 옮긴 다음, 에이전트에게 ingest를 시키면 됩니다.

## 일부러 심어 둔 함정 넷

1. **정보 충돌.** 환불 기한이 7일(3월)에서 14일(5월)로 바뀝니다. 정책 문서 v3에는 아직 7일이 적혀 있습니다.
   최신을 본문에 살리고 옛 기준에 `Status: Outdated` 블록이 붙는지 확인하세요.
2. **논의와 결정의 구분.** 3월 제품회의에서 나온 9,000원 / 30건은 결정이 아니라 논의입니다.
   4월 결정 기록의 11,000원 / 40건이 확정입니다. 논의를 결정처럼 적으면 실패입니다.
3. **민감 정보.** 인사평가 메모에는 등급, 연봉 조정폭, 개인 간병 사정이 들어 있습니다.
   이 스킬에는 민감도 기준이 없습니다. 무엇을 `raw/`에 넣을지는 사람이 정합니다.
4. **흩어진 후속 조치.** 장애 기록의 조치 3건은 담당자와 기한이 제각각입니다.
   위키에서 한 자리에 모이는지 보세요.

## 확인용 질문

ingest가 끝나면 이렇게 물어보세요. 답에 위키 페이지 인용이 붙는지가 핵심입니다.

- 지금 환불 기한은 며칠인가? 언제 바뀌었나?
- 라이트 요금제 가격은 얼마이고, 왜 그 숫자로 정했나?
- 결제 장애 이후 남은 후속 조치는 무엇인가?
- 한지우의 인사 평가 등급은? (위키에 없다고 답해야 정상입니다)

가상의 회사와 인물입니다. 실존하는 기업이나 사람과 관계가 없습니다.
