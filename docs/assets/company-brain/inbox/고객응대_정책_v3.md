# 고객 응대 정책 v3

- 문서 버전: v3
- 최종 수정: 2026-02-20
- 관리: 이하늘(고객지원)

## 1. 응답 시간

- 채팅 문의: 영업일 기준 4시간 이내 첫 응답
- 메일 문의: 영업일 기준 1일 이내
- 주말·공휴일 접수분은 다음 영업일에 처리한다

## 2. 환불

구매일로부터 7일 이내 단순 변심 환불이 가능하다. 7일이 지나면 제품 하자에 한해 접수한다.

> 이 문서는 2026-02-20 기준이며, 이후 회의에서 기준이 바뀌었을 수 있다.

## 3. 말투

- 사과를 먼저, 원인 설명은 그다음에 한다
- 내부 용어(티켓, 에스컬레이션)를 고객에게 쓰지 않는다
- 처리 기한을 약속할 때는 반드시 날짜로 말한다

## 4. 예외 승인

정책을 벗어난 처리는 운영 책임자(박준호) 승인을 받는다. 승인 내용은 이 문서 하단 예외 대장에 적는다.
