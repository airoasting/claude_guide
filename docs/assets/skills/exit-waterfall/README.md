# 엑싯 워터폴 계산기 (Exit Waterfall)

캡테이블과 우선주 조건을 넣으면 매각 금액대별로 누가 얼마를 가져가는지 계산해 주는 Claude 스킬입니다.

## 이 스킬이 하는 일

지분율 표는 매각 시 분배를 알려주지 않습니다. 청산우선권이 붙는 순간 지분율과 실수령액이 어긋나기 때문입니다. 지분 16.7%를 가진 시리즈B가 400억 매각에서 40.8%를 가져가는 상황이 실제로 일어납니다.

이 계산이 어려운 이유는 각 우선주가 "우선권을 받을지, 포기하고 보통주로 전환할지"를 선택하고, 그 선택이 다른 주주의 몫을 바꾸며 서로 물고 물리기 때문입니다. 그래서 협상 자리에서는 대개 감으로 말합니다. 이 스킬은 모든 조합을 계산해 **아무도 자기 선택을 바꿔 더 받을 수 없는 상태** 하나를 찾아 제시합니다.

## 언제 쓰나

- "엑싯 시뮬레이션", "매각하면 얼마 받나"
- "워터폴 계산", "청산우선권 반영해서 계산해줘"
- "이 조건이면 창업자한테 얼마 남나", "전환이 유리한 지점"
- "캡테이블 분배", "우선주 조건 비교해줘"

다음 경우에는 발동하지 않습니다. 기업가치 산정, 피치덱 스크리닝, 재무 실사, 텀시트 조항의 법률 해석, 세금 계산, 스톡옵션 행사 소득세 질의입니다.

## 입력과 출력

**입력 (필수)**

- 주주별 보유 주식 수 (보통주, 종류별 우선주, 스톡옵션 풀)
- 라운드별 투자금액

**입력 (조건)**

지정하지 않으면 아래 기본값을 쓰고, 기본값을 썼다는 사실을 산출물에 표시합니다.

| 항목 | 기본값 |
|---|---|
| 청산우선권 배수 | 1배 |
| 참가 여부 | 비참가적 |
| 참가 상한 | 없음 |
| 우선순위 | 후순위 라운드 우선 |
| 희석방지 | 계산하지 않는다. 조정 후 주식 수를 직접 입력 |

텀시트나 주주간계약 파일을 주면 조건을 읽어 채우고, 읽어낸 조항을 원문과 함께 보여줍니다.

**출력**

워터폴 리포트 HTML 한 장입니다. 캡테이블과 적용 조건, 시나리오별 분배표(금액, 지분율 대비, 투자 배수), 분배 구성 막대, 분기점 목록, 읽는 법, 계산 전제 순입니다.

## 분기점이란

이 스킬이 찾아주는 네 종류의 매각가입니다.

| 분기점 | 뜻 |
|---|---|
| 보통주 첫 수령 | 우선변제 총액을 넘어 보통주에 처음 돈이 가는 지점 |
| 우선주 전환 | 우선권을 포기하고 보통주로 바꾸는 편이 유리해지는 지점 |
| 참가 상한 도달 | 참가적 우선주의 수령액이 상한에 닿아 멈추는 지점 |
| 지분율 수렴 | 실수령 비율이 명목 지분율에 가까워지는 구간 |

협상에서 조건 하나를 바꿨을 때 이 지점들이 어디로 움직이는지 보면, 그 조건이 실제로 무엇을 바꾸는지 알 수 있습니다.

## 검산

모든 시나리오에서 주주별 수령액의 합이 매각 대금과 일치하는지 확인합니다. 일치하지 않으면 결과를 내지 않고 어느 단계에서 어긋났는지 보고합니다. 이 검산은 건너뛰지 않습니다.

## 주의

세금을 계산하지 않습니다. 모든 금액은 세전입니다. 거래 비용, 에스크로, 언아웃, 진술보장 유보금은 사용자가 금액을 지정해야 반영합니다. 텀시트 조항의 법적 효력은 해석하지 않고 숫자로 옮기기만 합니다. 매각을 권하거나 조건의 좋고 나쁨을 평가하지 않습니다.
