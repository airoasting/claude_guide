# 실사 레드플래그 스캐너 (DD Red Flag)

인수 검토 대상의 재무제표를 열두 개 점검 항목으로 훑어, 실사에서 먼저 파고들어야 할 곳을 위험도별로 정리해 주는 Claude 스킬입니다.

## 이 스킬이 하는 일

사모펀드, 벤처캐피탈, M&A 담당자의 실사 범위 설정을 돕습니다. 실사 기간은 짧고 확인할 계정은 많아서, 어디에 시간을 쓸지 정하는 일이 실사의 절반을 차지합니다. 그런데 그 판단 기준은 대개 경험 많은 한 사람에게만 있고 팀에 공유되지 않습니다.

이 스킬은 그 기준을 열두 개 항목으로 꺼내 놓습니다. 각 항목은 숫자 하나가 아니라 **두 숫자의 관계**를 봅니다. 매출채권이 늘어난 것 자체는 문제가 아니고, 매출보다 빠르게 늘어난 것이 신호이기 때문입니다.

상장사는 기업명이나 종목코드만 주면 DART 공시 데이터를 직접 조회합니다. 비상장사는 재무제표와 감사보고서를 받아 읽습니다.

## 언제 쓰나

- "재무 실사 해줘", "실사 전에 볼 것 정리해줘"
- "이 재무제표 이상한 데 없나", "레드플래그 찾아줘"
- "인수 대상 재무 점검", "회계 위험 스크리닝"
- "감사보고서 봐줘"

다음 경우에는 발동하지 않습니다. 투자 매력도 평가나 밸류에이션, 피치덱 1차 스크리닝, 투심 메모 작성, 실적 리포트 생성, 단순 재무비율 계산, 세무 자문입니다.

## 열두 개 점검 항목

| 항목 | 보는 관계 |
|---|---|
| 매출채권 회전 | 매출채권 증가율과 매출 증가율의 차이 |
| 재고 적체 | 재고자산 증가율과 매출원가 증가율의 차이 |
| 매출 인식 시점 | 4분기 매출이 연간에서 차지하는 비중의 변화 |
| 특수관계자 거래 | 매출과 매입에서 특수관계자가 차지하는 비중 |
| 이익의 질 | 영업활동현금흐름과 당기순이익의 괴리 |
| 우발부채 | 지급보증, 계류 소송, 약정 사항의 규모 |
| 감사 이력 | 감사인 변경, 감사의견, 강조사항, 핵심감사사항 |
| 대손 정책 | 대손충당금 설정률의 하락 여부 |
| 비용의 자산화 | 개발비 자본화 비율, 무형자산 손상 이력 |
| 차입 구조 | 단기차입 비중, 1년 내 만기 도래액과 보유 현금 |
| 경영진 관련 거래 | 임원 대여금, 보수 총액의 급변 |
| 종속회사 | 연결과 별도의 손익 차이, 손실 집중 |

## 발견 사항을 쓰는 방식

각 발견은 네 줄로 정리합니다. 순서를 바꾸지 않습니다.

1. 관찰한 숫자
2. 왜 신호인가
3. **문제가 아닐 수 있는 경우**
4. 실사에서 확인하는 방법

3번이 핵심입니다. 이것을 빼면 리포트는 고발장이 됩니다. 숫자의 이상은 대개 여러 설명을 갖기 때문에, 반대 설명을 함께 적어야 실사 팀이 균형 있게 접근합니다.

## 위험도 3단계

| 등급 | 뜻 |
|---|---|
| 높음 | 실사 범위에 반드시 넣는다 |
| 중간 | 대상 회사에 질의한다. 답변에 따라 등급이 오르내린다 |
| 낮음 | 기록만 남기고 실사 범위에 넣지 않는다 |

높음이 하나도 없으면 "높음 없음"이라고 명시합니다. 억지로 만들지 않습니다.

## 출력

실사 스크리닝 리포트 HTML 한 장입니다. 요약, 대상 개요와 데이터 출처, 높음 항목 상세, 중간 항목 상세, 낮음 항목 일괄 표, 대상 회사에 보낼 실사 요청 자료 목록, 데이터 한계 순으로 구성됩니다.

## 주의

이 리포트는 회계감사도 법적 판단도 아닙니다. 분식회계나 부실 같은 단정적 표현을 쓰지 않고, 관찰과 확인 방법만 적습니다. 공시나 제공 자료에 없는 숫자는 추정으로 채우지 않고 확인 불가로 남깁니다. 인수 여부와 가격 조정은 이 스킬이 결정하지 않습니다.
