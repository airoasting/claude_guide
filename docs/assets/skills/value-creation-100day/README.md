# 인수 후 100일 계획 (Value Creation 100-Day Plan)

투심에서 통과한 투자 논거를, 인수 직후 100일 안에 확인 가능한 행동으로 바꿔 주는 Claude 스킬입니다.

## 이 스킬이 하는 일

투자 논거는 대개 문장으로 남습니다. "원가 구조를 개선한다", "영업을 조직화한다" 같은 문장입니다. 이 문장은 인수 직후 아무 지시도 되지 못합니다. 누가, 언제까지, 무엇을 보고 성공을 판단하는지가 없기 때문입니다.

이 스킬은 논거를 30일, 60일, 100일 마일스톤으로 쪼개고, 항목마다 담당자, 지표, 판단 시점, **중단 조건**을 붙입니다. 중단 조건이 없으면 안 되는 일에 100일을 다 쓰게 되므로, 이 항목을 비운 계획은 만들지 않습니다.

100일이 기준인 이유는 두 가지입니다. 인수 직후는 조직이 변화를 예상하고 있어 저항이 가장 낮고, 100일이 지나면 새 경영진의 방식이 굳어져 그때부터 바꾸기가 훨씬 어려워집니다.

## 언제 쓰나

- "100일 플랜 짜줘", "인수 후 계획", "PMI 계획"
- "밸류업 플랜", "가치제고 계획"
- "인수 직후 뭐부터 해야 하나", "포트폴리오사 실행 계획"

다음 경우에는 발동하지 않습니다. 투자 검토 단계의 판단, 재무 실사, 매각 분배 계산, 일반 경영 컨설팅이나 조직 진단, 신규 사업 기획, 이미 보유 중인 회사의 정기 모니터링 보고서입니다.

## 입력과 출력

**입력**

- 투심 메모 또는 투자 논거
- 실사 보고서의 개선 항목
- 대상 회사 조직도, 인원 구성
- 재무제표와 사업계획
- 인수 조건 (지분율, 매도인 잔류 여부, 주주간계약의 사전동의 사항)

매도인 잔류 여부는 반드시 확인합니다. 창업자가 대표로 남는 구조와 경영진을 전면 교체하는 구조는 첫 30일에 할 수 있는 일이 완전히 다릅니다.

**출력**

100일 계획서 HTML 한 장입니다. 인수 개요와 지키려는 투자 논거, 100일 타임라인, 트랙별 항목 상세, 첫 30일 주 단위 일정, 지표판, 중단 조건 요약표, 이 계획이 다루지 않는 것 순입니다.

## 네 개 트랙

트랙은 늘리지 않습니다. 다섯 개를 넘으면 100일 안에 아무것도 끝나지 않습니다.

| 트랙 | 다루는 것 |
|---|---|
| 현금 | 운전자본, 지출 통제, 차입 상환 계획 |
| 원가 | 구매 구조, 특수관계 거래, 생산성 |
| 매출 | 거래처 구성, 가격, 영업 체계 |
| 관리 | 결산 주기, 지표 체계, 인사와 권한 |

각 트랙에 항목은 최대 세 개입니다. 트랙 4개 × 항목 3개, 총 12개가 상한입니다.

## 항목마다 붙는 다섯 가지

| 요소 | 규칙 |
|---|---|
| 행동 | 명사가 아니라 동사로 쓴다 |
| 담당 | 직책이 아니라 사람을 지정한다. 미정이면 언제까지 정할지 적는다 |
| 지표 | 숫자로 쓴다 |
| 판단 시점 | 30일, 60일, 100일 중 하나 |
| 중단 조건 | 어떤 상태가 되면 이 항목을 접는가 |

중단 조건이 비어 있는 항목은 계획에 넣지 않습니다.

## 첫 30일의 원칙

첫 30일에는 새로운 것을 시작하지 않습니다. 세 가지만 합니다.

- **막는다** 현금이 새는 곳을 먼저 닫는다
- **본다** 월 단위 결산과 핵심 지표를 볼 수 있게 만든다
- **듣는다** 주요 인력과 거래처를 직접 만난다

원가 절감이나 조직 개편은 30일 이후에 시작합니다. 무엇이 왜 그렇게 되어 있는지 모르는 상태에서 손대면 되돌리는 데 더 오래 걸리기 때문입니다.

## 주의

100일 안에 끝나지 않을 일은 넣지 않습니다. 설비 투자, 신제품 개발, 해외 진출은 이 계획의 대상이 아닙니다. 인원 감축은 기본 항목이 아니며, 사용자가 명시적으로 요청한 경우에만 법적 절차와 비용을 함께 적습니다. 실사에서 확인되지 않은 개선 여지는 계획에 넣지 않고, 목표 숫자에는 산출 근거를 붙입니다.
