# 인수 후 100일 계획

투심에서 통과한 논거를, 인수 직후 100일 안에 확인 가능한 행동으로 바꾸는 스킬이다.

## 이 스킬이 푸는 문제

투자 논거는 대개 문장으로 남는다. "원가 구조를 개선한다", "영업을 조직화한다" 같은 문장이다. 이 문장은 인수 직후 아무 지시도 되지 못한다. 누가, 언제까지, 무엇을 보고 성공을 판단하는지가 없기 때문이다.

100일이 기준인 이유는 두 가지다. 첫째, 인수 직후는 조직이 변화를 예상하고 있어 저항이 가장 낮다. 둘째, 100일이 지나면 새 경영진의 방식이 굳어져 그때부터는 바꾸기가 훨씬 어려워진다.

이 스킬은 논거 하나마다 **중단 조건**을 붙인다. 계획이 틀렸을 때 언제 접을지를 처음부터 정해 두지 않으면, 안 되는 일에 100일을 다 쓰게 된다.

## 입력

- 투심 메모 또는 투자 논거
- 실사 보고서에서 나온 개선 항목
- 대상 회사 조직도, 인원 구성
- 재무제표와 사업계획
- 인수 조건 (지분율, 매도인 잔류 여부, 주주간계약의 사전동의 사항)

매도인 잔류 여부는 반드시 확인한다. 창업자가 대표로 남는 구조와 경영진을 전면 교체하는 구조는 첫 30일에 할 수 있는 일이 완전히 다르다.

## 구조

계획은 네 개 트랙으로 나눈다. 트랙을 늘리지 않는다. 다섯 개를 넘으면 100일 안에 아무것도 끝나지 않는다.

| 트랙 | 다루는 것 |
|---|---|
| 현금 | 운전자본, 지출 통제, 차입 상환 계획 |
| 원가 | 구매 구조, 특수관계 거래, 생산성 |
| 매출 | 거래처 구성, 가격, 영업 체계 |
| 관리 | 결산 주기, 지표 체계, 인사와 권한 |

각 트랙에 항목을 최대 세 개까지 둔다. 트랙 4개 × 항목 3개, 최대 12개가 100일 계획의 상한이다.

## 각 항목에 반드시 붙이는 다섯 가지

1. **행동** 무엇을 하는가. 명사가 아니라 동사로 쓴다
2. **담당** 누가 하는가. 직책이 아니라 사람을 지정한다. 정해지지 않았으면 "미정"으로 남기고 언제까지 정할지 적는다
3. **지표** 무엇을 보고 됐다고 하는가. 숫자로 쓴다
4. **판단 시점** 30일, 60일, 100일 중 언제 확인하는가
5. **중단 조건** 어떤 상태가 되면 이 항목을 접는가

5번을 비운 항목은 계획에 넣지 않는다.

## 첫 30일의 원칙

첫 30일에는 새로운 것을 시작하지 않는다. 세 가지만 한다.

- **막는다** 현금이 새는 곳을 먼저 닫는다
- **본다** 월 단위 결산과 핵심 지표를 볼 수 있게 만든다
- **듣는다** 주요 인력과 거래처를 직접 만난다

원가 절감이나 조직 개편은 30일 이후에 시작한다. 무엇이 왜 그렇게 되어 있는지 모르는 상태에서 손대면 되돌리는 데 더 오래 걸린다.

## 산출물

100일 계획서 HTML 한 장.

1. 인수 개요와 이 계획이 지키려는 투자 논거
2. 100일 타임라인 (30일, 60일, 100일 구간별 항목)
3. 트랙별 항목 상세 (다섯 가지 필수 요소)
4. 첫 30일 상세 일정 (주 단위)
5. 지표판 (인수 시점 값, 100일 목표, 보유 기간 목표)
6. 중단 조건 요약표
7. 이 계획이 다루지 않는 것

## 하지 않는 것

- 100일 안에 끝나지 않을 일을 넣지 않는다. 설비 투자, 신제품 개발, 해외 진출은 100일 계획의 대상이 아니다.
- 인원 감축을 기본 항목으로 넣지 않는다. 사용자가 명시적으로 요청한 경우에만 다루고, 그때도 법적 절차와 비용을 함께 적는다.
- 실사에서 확인되지 않은 개선 여지를 계획에 넣지 않는다.
- 목표 숫자를 근거 없이 만들지 않는다. 각 지표의 목표치에 산출 근거를 붙인다.
- 매도인이 대표로 남는 구조에서 사전동의 사항을 무시한 계획을 세우지 않는다.
