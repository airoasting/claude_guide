# 트랙별 항목 후보와 중단 조건

100일 계획을 처음부터 백지에서 짜면 매번 다른 계획이 나온다. 이 목록은 출발점이다. 대상 회사에 맞는 것을 고르고, 맞지 않는 것은 버린다.

트랙은 넷을 넘지 않는다. 각 트랙의 항목은 셋을 넘지 않는다. 열두 개가 상한인 이유는 100일이 짧아서다.

## 현금

| 항목 | 지표 | 중단 조건의 방향 |
|---|---|---|
| 초과 채권 회수 | 회전일수 며칠 단축 | 초과분이 계약상 결제 조건 때문이면 회수 대신 조건 재협상 |
| 지출 결재 한도 재설정 | 대상 지출 사전 승인율 | 발주 지연이 납기 사고로 이어지면 한도 상향 |
| 재고 감축 | 재고일수 며칠 단축 | 수주잔고가 뒷받침되는 재고면 감축 중단 |
| 차입 상환 계획 대조 | DSCR 유지 수준 | 두 달 연속 약정 미달이면 대주단 협의로 전환 |
| 선급금과 미수금 정리 | 정리 금액 | 거래처 관계를 흔들 정도면 분할 회수로 전환 |

## 원가

| 항목 | 지표 | 중단 조건의 방향 |
|---|---|---|
| 특수관계 거래 대체 | 이전 물량 비율, 연 절감액 | 품질 승인 실패가 반복되면 단가 재협상으로 전환 |
| 구매 단가 재협상 | 상위 품목 단가 인하율 | 공급 중단 위험이 절감액을 넘으면 중단 |
| 설비 가동률 실측 | 라인별 데이터 확보 | 계측 투자가 일정 금액을 넘으면 수기 집계로 대체 |
| 외주 내재화 검토 | 대상 공정 수 | 인력 충원이 전제되면 100일 이후로 이월 |
| 불량률 집계 체계 | 공정별 집계 시작 | 현장 저항이 크면 한 개 라인만 시범 |

## 매출

| 항목 | 지표 | 중단 조건의 방향 |
|---|---|---|
| 주요 거래처 방문 | 방문 완료, 발주 계획 확인 | 면담 거부는 그 자체가 답이다. 거래 축소 시나리오로 전환 |
| 신규 거래처 승인 착수 | 후보 선정, 신청 건수 | 담당자 없이 착수하지 않는다. 채용이 늦으면 이월 |
| 품목별 수익성 분석 | 상위 품목 공헌이익 산출 | 원가 배부 정비가 길어지면 대상 품목 축소 |
| 가격 인상 검토 | 대상 품목과 인상률 | 거래처 반발이 물량 감소로 이어지면 중단 |
| 이탈 고객 사유 확인 | 인터뷰 건수 | 대상이 응하지 않으면 내부 기록으로 대체 |

## 관리

| 항목 | 지표 | 중단 조건의 방향 |
|---|---|---|
| 월 결산 마감 단축 | D+며칠 달성, 연속 개월 수 | 인력 충원 없이 불가능하면 목표를 낮춘다 |
| 핵심 직무 채용 | 임용 확정 시점 | 후보 확보에 실패하면 외부 자문 계약으로 대체 |
| 주간 경영회의 신설 | 연속 개최 주 수 | 대표 참석률이 낮으면 격주로 조정하고 사유 확인 |
| 지표판 구축 | 갱신 주기 | 데이터 수집이 수작업이면 지표 수를 줄인다 |
| 권한 규정 정비 | 규정 개정 완료 | 사전동의 대상이면 대주주 동의를 먼저 받는다 |
| 인력 조정 (요청 시에만) | 협의 착수 시점 | 필수 직무 공백이 생기면 대상에서 빼고 규모를 줄인다 |

## 중단 조건을 쓰는 법

중단 조건은 "안 되면 그만둔다"가 아니다. **어떤 신호를 보면, 무엇으로 바꾸는가**를 적는 것이다. 세 요소가 들어가야 한다.

1. 관찰 가능한 신호 (횟수, 비율, 기한)
2. 그때 하는 행동 (중단, 축소, 이월, 다른 방법으로 전환)
3. 왜 그것이 더 나은가 (한 문장)

3번을 빼면 담당자가 판단 시점에 그 조건을 무시한다. 이유를 모르는 규칙은 지켜지지 않는다.

## 매도인 잔류 여부에 따른 차이

| 구조 | 첫 30일에 할 수 있는 것 |
|---|---|
| 창업자가 대표로 잔류 | 관찰과 자료 확보 위주. 인사와 조직 변경은 사전동의 대상인지 먼저 확인 |
| 경영진 전면 교체 | 지출 통제와 결산 체계를 즉시 바꿀 수 있다. 대신 현장 지식이 함께 나가므로 인수인계 항목을 추가 |
| 전문경영인 신규 선임 | 선임 시점까지 공백이 생긴다. 그 기간의 의사결정 권한을 명시 |
