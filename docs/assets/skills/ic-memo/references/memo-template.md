# 투심 메모 양식

빈칸을 채우는 순서가 곧 작성 순서다. 위에서부터 채운다. 채우지 못한 칸은 지우지 말고 "미수령"이라고 적는다. 빈칸이 남은 메모가 빈칸 없이 매끄러운 메모보다 낫다. 심의는 그 빈칸을 놓고 하는 것이기 때문이다.

## 숫자 표시

모든 숫자 뒤에 셋 중 하나를 붙인다.

| 표시 | 붙이는 경우 | 함께 적는 것 |
|---|---|---|
| 확인 | 실사에서 원자료로 검증 | 검증한 자료명 |
| 미확인 | 대상 회사 제시, 검증 못 함 | 검증하지 못한 이유 |
| 추정 | 우리 쪽에서 만든 숫자 | 사용한 가정 |
| 미수령 | 자료가 없어 숫자를 못 씀 | 무엇을 받아야 채워지는지 |

계산으로 나온 값에도 표시를 붙인다. 재료 중 가장 약한 표시를 이어받고, 가정이 들어갔으면 추정이다. 경고를 켜는 기준은 SKILL.md에 있다.

## 1. 거래 요약

| 칸 | 채우는 법 |
|---|---|
| 대상 회사 | 상호, 설립연도, 업종, 상장 여부 |
| 인수 지분 | 비율과 매도인 |
| 기업가치 | 금액과 산출 배수. 배수 근거는 4번에서 |
| 순차입금 | 차입금에서 현금을 뺀 값 |
| 지분가치 | 기업가치에서 순차입금을 뺀 값 |
| 지분 대가 | 지분가치 × 인수 비율 |
| 거래 비용 | 자문료, 인수금융 취급 수수료 |
| 자금 조달 | 출자와 차입의 금액, 비중, 조건 |
| 승인 요청 사항 | 번호를 붙인 목록. 심의위원이 표결하는 대상 |

이 섹션은 첫 페이지 안에서 끝난다.

## 2. 투자 논거

세 문장 이내로 쓴다. 각 문장은 하나의 이유만 담는다. "성장성이 있고 팀도 좋고 가격도 싸다" 같은 문장은 이유가 셋이라 검증할 수 없다.

## 3. 대상 회사와 시장

사업 구조, 매출 구성과 거래처 집중도, 진입장벽의 실체, 시장의 방향. 각 문단은 근거 자료를 밝히고 시작한다.

## 4. 재무와 밸류에이션

3개년 실적 표(매출, 영업이익, EBITDA, 마진, 영업활동현금흐름, 순차입금)와 확인 상태. 이어서 가격 산정 표(비교 대상, 배수, 비고)와 본건 적용 배수. 비교 대상보다 높은 배수를 쓴다면 그 차이를 정당화하는 근거를 한 문장으로 적고, 그 근거가 확인되었는지 표시한다.

## 5. 실사 결과

영역(재무, 법무, 세무, 상업)별로 주요 발견과 반영 방식을 적는다. 반영 방식은 셋 중 하나다. 가격에 반영, 계약에 반영(거래 종결 조건이나 진술보장), 미해소.

## 6. 거래 구조

인수 구조, 매도인 잔류 조건, 거래 종결 조건, 진술보장과 에스크로. 매도인이 경영진으로 남으면 주주간계약의 사전동의 사항을 반드시 적는다.

## 7. 밸류업과 회수

보유 기간, 목표 지표, 회수 경로. 기본과 하방 두 시나리오를 표로 낸다. 각 행에 가정을 적는다. 매각 배수, 보유 기간, 부채 상환 속도를 숨기지 않는다.

## 8. 위험과 반대 논거

위험과 완화 방안 표를 먼저 쓰고, 반대 논거 세 가지를 뒤에 붙인다. 각 논거는 세 줄이다.

1. 이 딜을 거절해야 하는 이유 한 문장
2. 이 논거가 맞다면 벌어지는 일. 가능하면 금액이나 수익률로
3. 그럼에도 진행하는 이유. 없으면 "답 없음"

## 9. 자료 출처와 첨부

확인, 미확인, 추정 표시별 건수와 각각의 근거 자료를 나열한다. 첨부 문서 목록으로 마친다.
