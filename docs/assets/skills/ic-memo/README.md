# 투자심의 메모 작성기 (IC Memo)

실사에서 나온 자료를 투자심의위원회에 올릴 한 부의 문서로 정리해 주는 Claude 스킬입니다.

## 이 스킬이 하는 일

투심 메모는 딜을 담당한 사람이 씁니다. 그 사람은 이미 몇 달을 이 딜에 썼고 통과시키고 싶습니다. 그래서 메모는 자연스럽게 한쪽으로 기웁니다. 나쁜 숫자는 각주로 내려가고, 확인하지 못한 것이 확인한 것처럼 읽힙니다.

이 스킬은 두 가지 장치로 그 기울기를 막습니다.

**첫째, 모든 숫자에 확인 상태를 붙입니다.** 실사로 검증한 숫자, 대상 회사가 제시했으나 검증하지 못한 숫자, 우리 쪽 추정치를 표시로 구분합니다. 미확인과 추정이 재무 섹션의 절반을 넘으면 문서 상단에 경고를 표시합니다.

**둘째, 반대 논거를 의무로 씁니다.** 이 딜을 거절해야 하는 이유 세 가지가 없으면 메모가 완성되지 않습니다.

## 언제 쓰나

- "투심 메모 써줘", "IC 메모 초안"
- "투자심의 자료 만들어줘", "심의 메모 정리해줘"
- "딜 메모 작성", "투자 제안서 초안"

다음 경우에는 발동하지 않습니다. 피치덱 1차 스크리닝, 재무 이상 징후 탐지, 매각 분배 계산, 인수 후 실행 계획, 상장사 리서치, LP 보고서 작성입니다.

## 입력과 출력

**입력**

- 실사 보고서 (재무, 법무, 세무, 상업)
- 대상 회사 재무제표, 사업계획
- 시장 조사 자료
- 거래 조건 (지분율, 가격, 자금 조달 구조)
- 펀드의 투자 기준 (목표 수익률, 보유 기간, 티켓 사이즈)

자료가 적으면 적은 대로 씁니다. 채우지 못한 섹션은 공란으로 남기고 무엇이 필요한지 적습니다. 추정으로 메우지 않습니다.

**출력**

투자심의 메모 HTML 한 장입니다. 여덟 섹션으로 구성됩니다.

| 섹션 | 담는 것 |
|---|---|
| 거래 요약 | 대상, 지분율, 가격, 자금 조달, 승인 요청 사항 |
| 투자 논거 | 왜 이 회사를 지금 사는가 (세 문장 이내) |
| 대상 회사와 시장 | 사업 구조, 고객, 경쟁 위치, 시장 규모 |
| 재무와 밸류에이션 | 과거 실적, 사업계획, 배수 비교, 가격 근거 |
| 실사 결과 | 영역별 발견과 가격 또는 계약 반영 방식 |
| 거래 구조 | 인수 구조, 자금 조달, 종결 조건, 주주간 합의 |
| 밸류업과 회수 | 보유 기간 실행 계획, 회수 경로, 예상 수익률 |
| 위험과 반대 논거 | 주요 위험, 완화 방안, 반대 논거 세 가지 |

거래 요약은 첫 페이지 안에 끝납니다. 심의위원이 첫 장만 읽고도 무엇을 승인하는지 알 수 있어야 하기 때문입니다.

## 숫자 표시 규칙

| 표시 | 뜻 | 함께 적는 것 |
|---|---|---|
| 확인 | 실사에서 원자료로 검증 | 검증한 자료명 |
| 미확인 | 대상 회사 제시, 검증 못 함 | 검증하지 못한 이유 |
| 추정 | 우리 쪽에서 만든 숫자 | 사용한 가정 |

## 반대 논거 쓰는 법

세 가지를 각각 세 줄로 씁니다.

1. 이 딜을 거절해야 하는 이유 한 문장
2. 이 논거가 맞다면 무슨 일이 벌어지는가
3. 그럼에도 진행하는 이유, 또는 아직 답이 없으면 "답 없음"

세 번째에 답 없음이 하나라도 있으면 그대로 남깁니다. 지워서 통과시키지 않습니다. 심의는 그 항목을 놓고 하는 것이기 때문입니다.

## 주의

이 스킬은 투자 여부를 결정하지 않습니다. 승인 요청 사항만 적습니다. 실사 보고서에 없는 발견을 만들어 넣지 않고, 사업계획 숫자를 우리 전망으로 옮길 때는 미확인 표시를 붙입니다. 수익률을 계산할 때는 매각 배수, 보유 기간, 부채 상환 속도를 표로 함께 냅니다.
