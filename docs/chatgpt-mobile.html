라이브러리

생성한 결과물이 저장되는 공간입니다. 어느 대화에서 만들었는지 특정하기 어려울 때 여기에서 찾습니다.

프로젝트

지침과 참고 자료를 등록해 동일한 조건으로 작업을 반복하는 공간입니다. 설정 방법은 프로젝트 만들기에 있습니다.

원격

연결된 컴퓨터에서 실행 중인 작업을 스마트폰에서 확인하고 승인합니다. 실제 처리는 해당 컴퓨터에서 이뤄집니다.

플러그인

ChatGPT가 연동할 수 있는 도구를 추가하는 공간입니다. 등록하면 해당 도구를 사용하는 작업까지 대화 안에서 처리합니다.

여섯 개는 두 종류로 나뉩니다

이미지, 라이브러리, 프로젝트, 플러그인은 스마트폰에서 완결되는 기능입니다. 예약과 원격은 다른 환경에서 실행되는 작업을 스마트폰에서 확인하는 기능입니다.

Claude 앱과 다른 점

Claude는 스마트폰에서 작업을 맡기면 코드 작업인지 문서 작업인지 자동으로 배정합니다. ChatGPT는 그 배정을 사용자가 직접 합니다. 코드나 파일을 다루는 작업은 원격으로, 반복되는 작업은 예약으로 직접 보냅니다. 두 앱 비교는 스마트폰에서 Claude 쓰기에 있습니다.

원격

스마트폰에서 지시하고 컴퓨터가 실행합니다

회의 시작 5분 전
어제 올린 견적서 세 개 열어서 업체명이랑 금액, 납기만 표로 정리해 둬.
오전 9:12 · 나
회의 진행 50분
표로 정리했습니다. 금액은 A사가 가장 낮고, 납기는 C사가 2주 빠릅니다. 저장할까요?
오전 10:05 · ChatGPT
작업은 연결된 컴퓨터에서 실행됩니다

스마트폰은 지시를 보내고 결과를 받습니다. 실제 작업은 연결해 둔 Mac이나 윈도우에서 실행됩니다. 파일, 자격 증명, 설정은 그 컴퓨터를 떠나지 않고, 스마트폰에는 화면 캡처, 터미널 출력, 테스트 결과 같은 진행 상황만 전달됩니다. 승인이 필요하면 알림이 옵니다.

설정 순서

  1. 양쪽 기기를 같은 계정으로 연결합니다
    컴퓨터에 ChatGPT 데스크톱 앱, 스마트폰에 ChatGPT 앱을 설치하고 같은 계정으로 로그인합니다. 두 기기 모두 인터넷에 연결돼 있어야 합니다.
  2. 컴퓨터에서 Codex를 실행합니다
    데스크톱 앱의 Codex에서 원격 접속을 활성화합니다. 작업은 이 컴퓨터에서 실행되므로 절전 설정을 확인합니다.
  3. 스마트폰에서 작업을 보냅니다
    스마트폰 메뉴의 원격에서 연결된 컴퓨터를 선택하고 작업을 입력합니다. 브랜치 선택과 작업 공간 생성도 스마트폰에서 가능합니다.
사용 전 확인 사항
  • 연결한 컴퓨터가 깨어 있어야 합니다. 작업이 클라우드가 아니라 해당 컴퓨터에서 실행되기 때문입니다. 노트북을 닫으면 작업도 중단됩니다.
  • 회사 기기라면 정책을 먼저 확인합니다. 파일 접근을 허용하는 설정이라 IT 정책에 저촉될 수 있습니다.
  • 승인 알림을 확인하고 누릅니다. 되돌리기 어려운 작업일수록 무엇을 하려는지 읽어야 합니다.
  • 코드가 아닌 작업도 가능합니다. 다만 결과물이 파일로 남는 작업에 적합합니다. 답만 확인하고 끝나는 작업이라면 대화가 빠릅니다.
결과를 표로 받는 방법

표와 차트는 스마트폰에서도 대화 안에 표시됩니다. "표로 정리해 줘"를 덧붙이면 스크롤만으로 확인할 수 있습니다.

예약

반복 작업을 한 번만 정의합니다

동일한 작업을 매일 반복해서 지시하고 있다면 예약으로 전환합니다. 한 번만 정의하면 지정한 시각에 실행되고 결과를 알립니다.

작성 예시

매주 월요일 오전 8시에, 지난주 우리 업계 주요 뉴스를 다섯 줄로 정리해 줘. 출처 링크를 각 줄 끝에 붙이고, 확인 못 한 내용은 확인 못 했다고 적어 줘.
검토 없이 실행됩니다

예약은 검토하는 사람 없이 실행됩니다. 지시에 출처를 붙이라고 명시하고, 처음 몇 번은 결과를 직접 확인합니다. 근거는 AI의 환각을 벗어나는 법에 있습니다. 예약 실행은 Routines 예약 실행에서 자세히 다룹니다.

실행 순서와 확인 사항

실행 순서

1) 요금제부터 확인합니다

앱에서 설정을 열어 요금제를 확인합니다. 무료 플랜은 대화와 프로젝트, Codex까지 사용할 수 있습니다. 예약은 유료 플랜에서 제공됩니다.

2) 프로젝트를 생성합니다

가장 자주 지시하는 작업을 하나 선택하고, 매번 반복하던 설명을 프로젝트 지시문으로 옮깁니다. 5분이면 완료되고, 이후에는 같은 설명을 반복하지 않아도 됩니다.

우리 회사 보고서는 A4 두 장을 넘기지 않는다. 숫자를 먼저 쓰고 해석을 뒤에 붙인다. 확인하지 못한 수치는 추정이라고 명시한다.
3) 예약을 등록합니다

매일 확인하던 항목 하나를 등록합니다. 다음 날 결과를 확인하고 나머지 전환 여부를 판단합니다.

시작 전 확인 사항
  • 원격은 실제로 파일을 읽고 수정합니다. 되돌리기 어려운 작업은 승인 알림을 확인하고 누릅니다.
  • 회사 기기라면 정책을 먼저 확인합니다. 파일 접근과 원격 연결을 허용하는 설정입니다.
  • 입력할 정보의 범위를 미리 정합니다. 판단 기준은 AI와 안전하게 일하는 법에 다섯 가지로 정리돼 있습니다.

자주 묻는 질문

Q. 무료 플랜에서도 Codex를 쓸 수 있나요?

가능합니다. Codex는 무료를 포함한 모든 ChatGPT 플랜에서 제공됩니다. 다만 연결할 컴퓨터가 있어야 하고, 해당 컴퓨터가 켜져 있어야 합니다.

Q. 컴퓨터를 꺼 두고 스마트폰으로만 일을 시킬 수 있나요?

대화와 프로젝트는 가능합니다. 원격은 연결한 컴퓨터에서 작업이 실행되므로 해당 컴퓨터가 켜져 있어야 합니다.

Q. Claude 앱과 무엇이 다른가요?

Claude는 Dispatch에 맡기면 코드 작업과 문서 작업을 자동으로 배정합니다. ChatGPT는 원격과 예약 중에서 사용자가 직접 선택합니다. 대신 Codex는 무료 플랜에서도 제공됩니다.
