카드에 붙은 표기
Connect

과제를 실행하기 전에 연결해 두어야 하는 외부 서비스입니다. 부르는 이름은 제품마다 다릅니다. Claude 데스크톱 앱은 설정에서 커넥터를 연결하고, ChatGPT 데스크톱 앱은 작업 화면에서 플러그인을 지정합니다. 이 페이지의 표기는 Claude Cowork 기준입니다.

파일 시스템

내 컴퓨터의 파일을 읽고 쓰는 연결입니다. Claude Cowork에서는 작업할 프로젝트 또는 폴더를 지정하는 방식이고, ChatGPT Work에서는 Documents, PDF, Spreadsheets 같은 기본 플러그인이 같은 역할을 합니다.

Skill

그 과제에서 Claude가 수행하는 작업의 종류입니다. 따로 설치하거나 켜야 하는 항목은 아닙니다.

★★★★★ ~5분
▼

실행 순서

  • 3결과가 나오면 "Gmail로 나에게 보내줘"라고 요청해 이메일로 받습니다
기대 효과

실습 팁
  • 01번부터 순서대로 진행하면 난이도가 단계적으로 올라갑니다
  • 프롬프트를 그대로 한 번 실행해 본 뒤, 담당 업무에 맞게 내용을 고쳐 사용합니다
  • 결과가 기대와 다르면 구체적으로 다시 요청합니다. "표 형식으로 바꿔줘", "더 간결하게"처럼 지시하면 됩니다
  • 파일은 채팅창에 끌어다 놓으면 첨부됩니다
