★★☆☆☆
▼
프롬프트

04
GitHub 업로드
★★★☆☆
▼
프롬프트
1. GitHub.com 아이디 생성 2. New Repository 생성 3. API Key 생성 (프로필 → Settings → Developer Settings → Personal Access Tokens → Tokens Classic) 4. 해당 API Key를 AI에게 주고 파일 업로드(Push) : 절대로 메모리에 저장시키면 안됨, 보안 관리 5. GitHub.com에서 해당 Repo 클릭 → Settings → Pages → Branch에서 main, /root 선택하고 Save 6. 아이디.github.io/Repository명 으로 웹사이트로 접근
기대 효과
git init부터 commit, push, Pages 배포까지 자연어 한 줄로 끝냅니다. 내 작품이 인터넷에 공개되는 순간을 경험합니다.

07
CEO 데일리 브리핑 대시보드
★★★★★
▼
프롬프트
CEO 아침 브리핑 대시보드를 만들어줘. 오늘의 날씨, 환율·마켓, AI 비서가 요약한 업계 뉴스, AI 명언, 오늘 일정을 한 화면에 모은 개인 대시보드야. 중요: API 키 없이도 샘플(mock) 데이터로 완전히 작동하게 만들어줘. 그리고 설정 패널에서 본인 API 키(뉴스·날씨·환율)를 입력하면 실시간 데이터로 전환되도록 해줘. 뉴모피즘 스타일로.
기대 효과
API 키가 없어도 샘플(mock) 데이터로 대시보드가 완성된 채 돌아갑니다. 내 키를 연결하면 실시간 데이터로 바뀝니다. "키 없이 완성, 키 있으면 실시간"이라는 실전 앱 설계 패턴을 익힙니다.
