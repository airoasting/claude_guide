이름의 유래

Claude와 ChatGPT, 이름은 어디서 왔을까요?

Claude 사람 이름에서
Claude
C
클로드 섀넌벨 연구소에서 일한 수학자이자 전기공학자입니다.1937년 MIT 석사 논문에서 0과 1의 논리(불 대수)로 전기 회로를 설계할 수 있음을 보였습니다. 디지털 회로의 출발점입니다.1948년 논문 「통신의 수학적 이론」에서 정보의 양을 비트(bit) 단위로 재는 정보 이론을 세웠습니다.1955년 '인공지능(Artificial Intelligence)'이라는 말을 처음 쓴 다트머스 회의 제안서의 공동 제안자 네 명 가운데 한 명입니다.수상 미국 국가과학훈장(1966), IEEE 명예훈장(1966), 교토상(1985).Claude Shannon · 1916~2001 · 미국

0과 1로 정보를 다루는 토대를 세운 수학자입니다. 그가 만든 정보 이론이 오늘날 디지털 통신과 AI의 바탕입니다.

클라우드 클로드 [ klɔːd ]

Claude는 프랑스어에서 온 이름이라 영어 cloud처럼 읽지 않습니다.

Anthropic ← anthropos · 그리스어로 사람

2021년 아모데이 남매가 세웠습니다. 정관에 공익 목적을 넣은 공익 법인(PBC)입니다.

ChatGPT 기술 이름에서
Chat+GPT
  • Generative문장을 만들어 냅니다
  • Pre-trained대량의 글로 미리 학습했습니다
  • Transformer2017년 구글 논문이 제시한 신경망 구조입니다

이름 자체가 기술 설명입니다. 대화(Chat)에 모델 구조의 이름(GPT)을 그대로 붙였습니다.

OpenAI ← Open + AI

2015년 비영리 단체로 출발했습니다. 연구를 공개하겠다는 방향을 이름에 담았고, 2019년에 영리 부문을 두었습니다.

Claude가 만든 표준

Claude가 업계 선두가 된 기능

Anthropic은 대화창 밖에서 실제 작업을 처리하는 도구를 먼저 내놓았습니다. 외부 도구를 연결하는 표준(MCP), 터미널에서 돌아가는 실행 환경(Claude Code), 반복 업무를 묶는 업무 패키지(Skills) 세 가지입니다. 세 가지 모두 ChatGPT가 뒤따라 채택했습니다.

01 2024년 11월 공식 런칭

MCPModel Context Protocol

AI 모델과 외부 도구·데이터를 연결하는 오픈 표준 프로토콜입니다. Slack, GitHub, 데이터베이스, 로컬 파일처럼 서로 다른 시스템을 하나의 규격으로 연결합니다. 2025년 12월 9일에는 MCP를 리눅스 재단 산하 Agentic AI Foundation에 넘겼습니다. 창립 멤버에 Block과 OpenAI가 함께 이름을 올렸습니다.

업계 표준이 되었습니다. OpenAI, Google DeepMind, Microsoft가 모두 채택해, 지금은 AI를 외부 도구에 연결하는 사실상의 공통 규격입니다.

ChatGPT는 2025년 3월 26일 이 표준을 그대로 채택했습니다.

02 2025년 5월 공식 런칭

Claude Code터미널 기반 코딩 에이전트

터미널에서 저장소 전체를 읽고, 코드를 고치고, 테스트하고, 커밋까지 처리합니다. 2025년 2월 리서치 프리뷰로 시작해 Claude 4 공개와 함께 정식 출시했습니다.

에이전트 실행 환경의 기본값이 되었습니다. IDE 없이 명령줄 하나로 돌아가고, 서브 에이전트, MCP, 스킬을 한 번에 지휘합니다.

ChatGPT는 두 달 뒤인 2025년 4월 16일 Codex CLI를 냈습니다.

03 2025년 10월 공식 런칭

Skills재사용 가능한 업무 패키지

보고서 작성, 재무 분석, 코드 리뷰 같은 업무를 프롬프트·스크립트·템플릿으로 묶은 모듈입니다. 한 번 만들면 조직 전체가 같은 스킬을 불러 씁니다. 2025년 12월 18일에는 조직 단위 관리 기능이 추가되고 규격이 공개 표준으로 전환되었습니다.

개인의 노하우를 팀 자산으로 바꿉니다. 한 사람이 만든 업무 방식을 조직 전체가 같은 품질로 반복합니다.

ChatGPT는 2025년 12월 같은 SKILL.md 규격을 채택했습니다. 한 번 만든 스킬을 Claude와 Codex 양쪽에서 그대로 씁니다.

읽을 때 주의할 점
  1. 매출 집계 기준이 다릅니다. Anthropic은 AWS·Google Cloud를 거쳐 판매된 매출을 총액으로 넣고, OpenAI는 클라우드 파트너를 거친 판매를 넣지 않습니다. 같은 기준으로 맞추면 격차는 줄어듭니다.
