# 변경 로그 2026-10

### 2026-10-03 (에이전트 도구 안내 페이지 신설)

사용자 지시로 `docs/agents-tools.html`을 신설하고 인덱스 부록 '에이전트 도구'의 첫 카드로 넣었다. 기존 `agent-tools.html`(MCP·커넥터·스킬·플러그인 설명, 3단계)과는 다른 페이지다. 파일명이 한 글자 차이라 링크를 걸 때 주의한다.

- 헤르메스·Orca·Aside·Buzz·Instinct 다섯 도구를 도구마다 한 섹션(이름·한 줄 정의·팩트 4칸·하는 일 3장·이럴 때·주의점·다운로드 버튼)으로 정리했다. 마지막에 비교표와 상황별 선택 기준을 두었다.
- 공통 블록(헤더, 서브메뉴, 햄버거, 푸터, 스크립트)은 `orca.html`에서 가져왔다. 전용 CSS는 `에이전트 도구 안내 전용` 주석 블록 하나에 모았다. 다운로드 버튼 바탕은 `--accent-aa` 값 `#A84726`(흰 글자 5.84:1)이다.
- 헤르메스·Orca·Buzz의 사실과 다운로드 주소는 기존 상세 페이지 값과 맞췄다. Aside(aside.com, Aside Computer, YC F25, 2026년 6월 공개)와 Instinct(instinct.com, Spear Street Technology, 2026년 8월 공개, 미국 초대제)는 공식 사이트와 리뷰 기사로 확인했다. 확인되지 않은 Instinct 맥 앱과 Aside 가격은 적지 않았다. Aside·Instinct는 브랜드 로고 자산이 없어 다섯 도구 모두 라인 아이콘으로 통일했다.
- 인덱스: 부록 에이전트 도구 첫 줄을 `cards col-2`에서 3열 `cards`로 바꿔 6장이 3장씩 두 줄로 놓이게 했다.
- README Pages 배지 46→47, 부록 표에 행 추가. `AGENTS.md`·`MEMORY.md` 페이지 수, 페이지 인벤토리 `section-hermes` 행을 갱신했다.

데스크톱 1280px과 모바일 375px에서 가로 넘침 없음, 콘솔 오류 없음을 확인했다. 미커밋.

같은 날 사용자 지시로 이어서 고쳤다.

- 도구 순서를 헤르메스 → Aside → Orca → Buzz → Instinct로 바꿨다(Aside를 두 번째로). 서브메뉴, 도구 지도, TOOL 번호, 비교표, 선택 기준, 참고 링크, 메타 설명을 같은 순서로 맞췄다.
- Orca를 `멀티 모델 토론 작업대`로 다시 썼다. 같은 문제를 Claude Code·Codex·Cursor CLI에 맡기고, 답을 나란히 비교하고, 한 모델의 결과에 단 의견을 다른 모델에게 보내 검토받는 용도다. 공식 문서(`/docs/cli/orchestration`)상 에이전트끼리 직접 메시지를 주고받지 않고 조율 에이전트를 거치므로 본문에 그대로 밝혔다. `토론 진행 순서` 박스와 오케스트레이션 문서 참고 링크를 추가했다. `orca.html` 본문은 손대지 않았다.
- 섹션명 `고르는 기준`을 `선택 기준`으로 바꿨다.
- 인덱스 부록 에이전트 도구에서 `헤르메스 에이전트`·`Orca`·`Buzz` 카드를 뺐다. 남은 3장(`agents-tools`·`hermes-cases`·`liner-model-api`)을 한 줄 3열로 합치고 섹션 부제를 고쳤다. 페이지 파일은 지우지 않았다. README Pages 배지 47→44와 부록 표 3행 삭제.
- 인덱스에 남은 세 카드 페이지(`agents-tools`·`hermes-cases`·`liner-model-api`) 헤더에 3개 메뉴(`pages-agenttools`)를 넣었다. 라벨은 `에이전트 도구 안내`·`헤르메스 사용 사례`·`Liner Model API`, 아이콘은 인덱스 카드 아이콘과 같다. 폭은 3개 메뉴 기준 700px(버튼 224px)이다. `hermes-cases`의 옛 2개 메뉴(`hermes-agent`와 짝)는 이 3개 메뉴로 교체했고, `liner-model-api`는 메뉴가 없던 페이지라 새로 넣었다. `hermes-agent`의 2개 메뉴는 그대로 두었다. 모바일 375px에서 세로 3단으로 쌓이고 가로 넘침이 없음을 확인했다.
- 사용자 지시로 `hermes-agent.html`·`orca.html`·`buzz.html`을 `backups/`로 옮겼다. 남은 링크는 이렇게 처리했다. agents-tools의 설치 가이드 버튼 3개는 삭제하고 CTA는 `hermes-cases`로, hermes-cases CTA는 `agents-tools.html#sec2`(헤르메스 다운로드)로, claude-mobile FAQ 본문 링크도 `agents-tools.html#sec2`로 바꿨다. docs 루트 전체 내부 `.html` 링크 검사 결과 깨진 링크 0건이다. 페이지 전용 이미지와 영상은 남겨 두었다.
