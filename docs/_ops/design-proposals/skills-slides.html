A

테라코타 히어로 + 크림 카드

메인 페이지와 가장 가깝습니다. 표지와 단락 시작 장은 메인 히어로처럼 테라코타 그라디언트에 흰 제목, 가는 구분선, 반투명 알약을 씁니다. 본문 장은 메인 카드와 같은 크림 바탕의 뉴모피즘 카드에 테라코타 단계 배지를 붙입니다. 표지 아래 점선은 메인의 5단계 타임라인을 6가지 구성 요소로 옮긴 것입니다.
